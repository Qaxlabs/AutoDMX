# Support & Help

Welcome to AutoDMX! 👋 This document explains how to get help, ask questions, and find answers.

---

## 📖 Documentation

Start with the [**README**](./README.md) — it covers:

- What AutoDMX does
- Architecture overview
- Step-by-step setup and configuration
- How to deploy

For deeper details, browse the source — it's well-commented.

---

## 🐛 Found a bug?

**Open a [bug report](https://github.com/Qaxlabs/AutoDMX/issues/new?template=bug_report.md).**

Please include:

- A clear, descriptive title
- Steps to reproduce
- Expected vs. actual behavior
- Your environment (Node version, OS, deployment target)
- Relevant logs or screenshots (with secrets redacted!)

---

## 💡 Have a feature idea?

**Open a [feature request](https://github.com/Qaxlabs/AutoDMX/issues/new?template=feature_request.md).**

Describe the problem you're trying to solve and your proposed solution. Check existing issues first to avoid duplicates.

---

## 💬 Questions & discussion

For general questions, "how do I…?" topics, and community conversation, use [**GitHub Discussions**](https://github.com/Qaxlabs/AutoDMX/discussions).

This is the right place for:

- Setup help
- Architecture questions
- "Is this possible with AutoDMX?"
- Best practices and tips

---

## 🔒 Security issues

**Do not file public issues for security vulnerabilities.** See [`SECURITY.md`](./SECURITY.md) for private disclosure instructions.

---

- ⭐ **Star the repo** to be notified of releases
- 👀 **Watch** the repository for issue and PR activity
- 📝 Read the [**Changelog**](./CHANGELOG.md) for release notes

## 🤝 Contributing

Want to help make AutoDMX better? See the [**Contributing Guide**](./CONTRIBUTING.md) for development setup, the PR process, and style guides.

## ⏱️ Response times

This is an open-source project maintained by volunteers. We do our best to respond to issues and discussions within a few days. Critical security issues are prioritized — see [`SECURITY.md`](./SECURITY.md).

Please be patient and respectful. 🙏
